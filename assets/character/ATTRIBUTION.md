# Character attribution

The animated character in `sprite.webp` is made from this 3D model:

- **Title:** Cyber Samurai
- **Author:** [KhoaMinh](https://sketchfab.com/duongminhkhoa231)
- **Licence:** [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0)

**Changes made:** the model was rendered to 2D animation frames with [Blender](https://www.blender.org/)
and [Starforge](https://github.com/ShyneChikwapulo/Starforge): lighting was added, the textures were
set up as materials, and a small idle motion (a weight shift, a breath, a slow turn of the head, a
pulse in the glowing parts and a faint ripple in the robe) was animated. This does not imply the
author endorses this project.

This folder is covered by CC BY 4.0, not by the repository's MIT licence. If you swap in your own
character, replace this file with the credit your model's licence requires, or delete it if your
character needs none.
