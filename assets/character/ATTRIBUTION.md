# Character attribution

The animated character in `sprite.webp` is made from this 3D model:

- **Title:** 10000 Followers! Milestone - Shade of Neo-Tokyo
- **Author:** [Moon dong hwa](https://sketchfab.com/moondonghwa)
- **Source:** https://sketchfab.com/3d-models/10000-followers-milestone-shade-of-neo-tokyo-ce65f2fd429d40de9dac4eb60760dd90
- **Licence:** [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0)

**Changes made:** the speech bubble that comes with the model was removed, and the model was
rendered to 2D animation frames (a bust, lit and colour-graded to suit the card) with
[Starforge](https://github.com/ShyneChikwapulo/Starforge). This does not imply the author endorses
this project.

character, replace this file with the credit your model's licence requires, or delete it if your
character needs none.
